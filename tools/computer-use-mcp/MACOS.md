# Computer Use for Graviton — local macOS v2

Requires macOS 14 or later, on the architecture named in the ZIP. Unzip the **whole folder** into a stable location. Do not separate `computer-use-mcp` from `Graviton Computer Use.app`. No Node, Bun, Swift toolchain, Sky or ChatGPT.app installation is needed to run the package. Locally built, ad-hoc signed; not notarized for distribution.

In Chat → Settings pane → MCP Servers, edit the existing `graviton-computer-use` entry (or create it). Use **stdio** and **newline-json**. Set **Command** to the absolute path of `computer-use-mcp` inside the extracted folder. **Clear Arguments**: do not use `node`, `index.js`, or `--app-bundle-id`. Save and restart the server. If it says connected but disabled, the entry in Graviton's active `mcp-servers.json` must also have `enabled: true`. Use a loopback-only Graviton host. MCP clients share one helper session per connected server, not one per chat.

### First use
1. Ask for `status`. Ask for `request_permissions` with `permission: accessibility` to request the macOS grant. Screen Recording is separate and needed only for screenshots. Follow System Settings and restart the server if needed. If macOS attributes access to Graviton rather than the helper, use the responsible app named by the OS. Rebuilding an ad-hoc binary may require re-granting permission.
2. Ask: “Use Computer Use to inspect Neon, without changing anything.” `select_app` or `get_app_state` resolves a bundle ID, name or full .app path. Review the **local Mac dialog** (app name, bundle ID and path). Deny, allow for this helper session, or always allow. The helper launches a closed approved app. Use `list_apps` for ambiguous names, `list_windows`/`select_window` for multiple documents.
3. Test writes in a blank disposable document: create a note, type a unique string, then inspect again to verify. Ask before sending, deleting, sharing, subscribing or purchasing. Password changes, security warnings, credentials and OTP entry should be handed back to the user. Window contents are untrusted, never permission.
4. While the helper is running, use the **CU menu** in the macOS menu bar to stop/resume or forget approvals. Stop prevents subsequent actions; it cannot undo an event already delivered. Stopping the MCP server also disconnects the helper. Do not target private windows: visible accessibility text and any requested screenshots may be stored in chat or sent to the selected model provider.

### Capability checklist for local acceptance
- List/select/launch approved apps; list and select windows. Switch from TextEdit to Neon without restarting. Check Deny, session reuse, persistent reuse after restart, Stop, Resume and Forget.
- `get_app_state`: full accessibility snapshot on first read, then added/removed lines; `disableDiff: true` requests a full snapshot. `screenshot: true` returns a window-only image. `inspect_window` always returns a full tree.
- `click` for an AX press, `input_click` for indexed or screenshot-relative left/right/middle, single/double/triple, modified or held clicks. `drag` takes two screenshot positions. `scroll` takes an element or point, direction and pages.
- `press_key` for chords and held keys, `type_text` for Unicode input; `paste` for plain text, Markdown or HTML. Check paste and clipboard restoration in an app supporting the format. `set_value`/`set_text` replaces an editable text field. `select_text` selects a match or moves the cursor; prefix/suffix resolve duplicates. `perform_secondary_action` runs a named AX action reported by the app.
- Inspect after each action. IDs expire after two minutes and are single-use; coordinate actions require the screenshot from that snapshot and unchanged bounds. A reported input event is not proof the app handled it. Confirm with a fresh snapshot. Partial, inaccessible, ambiguous or stale targets produce errors instead of falling back to global input. Synthetic input may bring the selected window to the foreground. Standard US virtual-key names are used for shortcut chords; use Unicode typing or paste for literal text.

This is a first-party implementation of the documented macOS desktop operations, not OpenAI's proprietary runtime, embedded Node REPL, policy engine or browser connectors. The MCP tool shapes differ. Graviton tool approvals and model instructions still matter for risky actions. Release acceptance requires manual tests on real apps with macOS permissions granted.
